# Contributing to Polly

Thanks for your interest in Polly!

## Issues

Anyone is free to [file an issue](../../issues): bug reports, questions and ideas are all welcome. For a bug,
please say whether you use Polly on a Mac, iPhone or iPad and which OS version, which Nagios version the server
runs, and what you expected to see. If the problem is in what Polly reads from or sends to the server, a
`polly-debug.log` helps (see "Debugging" in [doc/architecture.md](doc/architecture.md#debugging)); check it for host names you'd rather not
share before attaching it.

## Code contributions

We can only accept code contributions under a Contributor License Agreement (CLA). We need it to be able to
publish updates of the app, including in the App Store, under our own name.

So if you'd like to contribute code, please contact us first, by opening an issue that describes what you
want to change, **before** you start working on it. We'll then discuss the change and the CLA with you. We
can't accept pull requests that weren't agreed on beforehand.

See [DEVELOPERS.md](DEVELOPERS.md) for building, running and testing the app, and [doc/architecture.md](doc/architecture.md) for
how it is put together.
